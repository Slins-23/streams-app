## DEPRECATED (Websites have updated and I haven't updated the code)

This app connects to a Python backend. It **WAS** hosted at Heroku, <a href="https://hub-stream.herokuapp.com/api">here</a>.
It is a simple Flutter app connected to a Python backend, which scrapes some streaming websites and returns results which are then displayed in the app.
Made for learning purposes and my newly bought Fire TV Stick, for ease of access.

Works for mobile but is unoptimized for any platform that is not a TV. Meaning there will probably be bugs, UI overflows, etc.

### This app was made for learning purposes, has many things that need improvement, redundant code, etc. Although I know exactly  what should be fixed/Improved, I don't intend to update this in the near future.
